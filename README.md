## 🚀 Projects:

🔗 https://github.com/Maisam-eng/Design-and-Verification-of-a-Simplified-Interrupt-Controller-Using-SystemVerilog-UVM

- Built full UVM testbench (driver, monitor, sequencer, scoreboard).
